# Mars Globe Textures Attribution

This directory contains global textures utilized by the 3D planetary globe view (`MarsGlobe.tsx`).

## 1. `mars_color.jpg` (8192×4096 Albedo Map)
- **Dataset:** Mars Global Color Mosaic / Viking MDIM 2.1
- **Source:** NASA / Jet Propulsion Laboratory (JPL-Caltech) & USGS Astrogeology Science Center
- **Credit:** NASA/JPL-Caltech/USGS
- **License / Terms:** Public Domain (NASA Open Data Policy)
- **Description:** Global true-color/color-corrected planetary mosaic reconstructed from Viking Orbiter visual camera observations.

## 2. `mars_bump.jpg` (8192×4096 Topographic Bump Map)
- **Dataset:** Mars Orbiter Laser Altimeter (MOLA) Global Elevation Model
- **Source:** NASA Goddard Space Flight Center (GSFC) / Planetary Data System (PDS) Geosciences Node
- **Credit:** NASA/GSFC/MOLA Science Team
- **Datum:** MOLA Areoid (IAU Mars 2000 Planetocentric)
- **License / Terms:** Public Domain (NASA Open Data Policy)
- **Description:** Global elevation bump displacement map derived from MGS MOLA altimetry profiles.
